# 伏笔

伏笔是提前可见、后来获得明确用途的细节。悬念提出问题，暗线持续推进未完全显露的事件，伏笔为答案留下证据；三者可以配合，但不能互相替代。

## 先写答案，再写线索

先确定最终事实，倒推什么痕迹必然存在。给痕迹一个初读时合理的解释，安排主角获得新证据，然后回收。初学者先练物件伏笔，验证成功后再扩展长线。

写作时另存一张简短账本：线索内容、首次出现位置、当时解释、真实含义、提醒位置、预计回收位置、是否已回收。不要把账本中的秘密直接写进正文。

## 公平性检查

读者回看能否找到原细节；初读时它是否自然；后来的解法是否遵守前面规则；知道答案的人有没有为了骗读者而在内心说谎；久未回收的线索是否得到适度提醒。只出现一次“神秘黑影”，最后说它就是幕后人，通常仍缺少可验证的联系。
