# 敌友重判与动机翻转

类型：原创示范｜翻转对象：行为动机｜适合：调查、追逐、阵营冲突。

## 核心机制

事实不变，动机获得新的证据。主角因此调整合作方式，但不必抹去对方造成的伤害。误判可以修正，责任仍然存在。

## 示例

齐叔连续三次阻止宋微进入旧实验楼。他剪断门禁、堵住侧门，甚至抢走她的通行卡。宋微认定他在替失踪案主谋销毁证据。

但每次堵门，齐叔都把人赶到上风处；他抢走卡，却留下了她的录音笔。

第四次，宋微找到旧楼的事故通报，又在门缝取到了异常粉尘的样本。里面的灵质会附着在呼吸者身上，通风停止后会从侧门逸出。

齐叔确实在阻拦她，也确实隐瞒了事情。他曾参与错误封存，害怕追责。他想保护外面的人，也想拖延旧事曝光。

宋微要求他交出通风图，并把当年的责任单交给调查组。两人合作救出困在地下的人，合作结束后，齐叔仍要接受问询。

## 反转结构

| 环节 | 内容 |
| --- | --- |
| 初始判断 | 阻止调查，所以属于幕后势力 |
| 旧解释的漏洞 | 保留录音、引导站位，对毁证并无帮助 |
| 新证据 | 事故记录与现场样本相互验证 |
| 新解释 | 保护与自保并存，目标没有主角想得单一 |
| 新行动 | 有条件合作，继续追责 |

## 怎么仿照

先替对方写出完整目标，再检查每次阻拦是否都服务于目标。放入至少一个“若真想害主角就不该这样做”的细节。揭晓通过记录、现场或选择完成，别只靠对方说自己有苦衷。

变体：抢夺资料的人想阻止名单泄露，但也想遮掩失职；追捕者知道主角携带危险物，却误信了上级命令。动机复杂不等于人人无辜。

## 参考建议与易错点

“都是为你好”不是证据，也不能合理化所有伤害。要解释为何不能直接沟通，并允许这个理由并不充分。若只要双方正常说两句话就能解除全部冲突，应缩短误会，改写成利益争执。

## 仿写练习

用对方视角写 200 字真实目标，再回到主角视角写 400 字误判与纠正。检查是否出现为了骗读者而不真实的内心独白。
