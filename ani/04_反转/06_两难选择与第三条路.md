# 两难选择与第三条路

类型：原创示范｜翻转对象：选择的前提｜适合：篇章高潮、谈判、团队协作。

## 核心机制

二选一通常建立在某个前提上。主角利用提前展示过的资源改变前提，得到新方案；新方案仍应付出代价，否则两难只是虚张声势。

## 示例

结界核心只能同时支撑一个区域。保住医院，旧街就会失守；保住旧街，医院必须立即撤离。两边的人都没有足够时间离开。

此前，周遥修过街区的五座旧祠灯。她知道它们各自能维持小范围结界，但必须由登记住户现场接续，不能远程控制。

她提出把旧街分成五个小区，居民分别点灯，大核心暂时留给医院。反对者指出，祠灯只能撑十分钟，周遥手里的备用灯芯也只够替换一次。

“那就不保整晚，保撤离这十分钟。”

广播改为逐段疏散。周遥把自己的能力抵押给主灯，换来最后一段稳定时间。人群撤出后，旧街的一排店铺仍被毁掉，她也失去一年的施术资格。

救下人不等于保住一切。下一段故事从安置和重建开始。

## 反转结构

| 环节 | 内容 |
| --- | --- |
| 二选一的前提 | 只能依赖一个大核心维持整晚 |
| 提前资源 | 五座可局部运行的旧祠灯及其限制 |
| 改变前提 | 从守住整晚改为争取分段撤离时间 |
| 执行条件 | 居民到位、路线明确、有人支付额外成本 |
| 保留代价 | 财产损失、能力停用、后续安置责任 |

## 怎么仿照

写出二选一背后未被质疑的条件：时间尺度、资源集中方式、谁必须亲自做事。用前文资源改变其中一项。让反方指出可行性缺口，主角补齐方案而非发表宣言。最后保留无法避免的损失。

变体：不必救走全部证据，先保留可复核样本；不必同时击败敌人，只需拆开其协作；不必独自承担契约，可以公开邀请自愿分担。涉及契约时先写明可分担规则。

## 参考建议与易错点

第三条路需要准备和执行能力，不能突然出现万能朋友。并非所有悲剧都应有完美解，有时人物必须在两难中选择。是否采用此法，应服从人物弧线和故事承诺。

## 仿写练习

列出两个坏选项及共同前提，再设计一个有新代价的第三方案。用 600 字写争论、修订与执行，结尾写出一项下章不能跳过的后果。
