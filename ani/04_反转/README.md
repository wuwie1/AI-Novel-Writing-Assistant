# 反转

反转让先前合理的判断失去充分性，并用新证据建立更完整的理解。读者不仅要惊讶，还要知道人物接下来为何改变行动。

## 最小写作单元

先写“大家以为……，因为看到了……；但另一个已出现的细节是……；新的验证证明……；因此主角决定……”。这五句如果接不起来，先补因果，再写惊讶反应。

第一次练习建议选世界显形或证据解释翻转。敌友重判更需要人物动机铺垫，第三条路更需要检查资源与时间是否真的够用。

意外出现新敌人、公布陌生身份、临时升级能力，并不天然构成好的反转。连续翻转也应保留已经成立的事实与成果；如果每个结论立刻被否定，读者会失去判断故事的依据。配合[伏笔](../03_伏笔/README.md)倒推准备。
