# 常用桥段

桥段是一段有因果的行动：角色要得到东西，遇到阻力，选择办法，付出成本，获得会改变后续的结果。先确定目标，再选择机制。

| 条目 | 什么时候用 | 难度 |
| --- | --- | --- |
| [低估高手与专业破局](01_低估高手与专业破局.md) | 主角有本事，却没有展示机会 | 入门 |
| [公开质疑与证据翻盘](02_公开质疑与证据翻盘.md) | 成果或资格被错误判断影响 | 入门 |
| [限时救场与代价选择](03_限时救场与代价选择.md) | 需要通过选择塑造担当 | 进阶 |
| [资源争夺与规则破局](04_资源争夺与规则破局.md) | 强弱悬殊，直接比力量缺少变化 | 进阶 |
| [小善意与延迟回报](05_小善意与延迟回报.md) | 想积累伙伴、信任与社区关系 | 入门 |
| [被逐出局与另起炉灶](06_被逐出局与另起炉灶.md) | 需要一条能延续多篇章的成长主线 | 进阶 |

难度是本库对练习复杂度的建议，不是作品价值排序。第一次写，建议从小善意或专业破局开始，只写一场完整行动。

## 选好以后怎么写

先填“主角想要什么—谁为什么阻止—主角用什么办法—谁承担代价—局面怎样改变”。写完再补环境和对话。连续采用相同桥段时，至少改变胜利条件、代价、关系后果之一，避免只换地点和对手等级。

桥段可以带来情绪，但不自动保证情绪。需要更明确的铺垫时，配合[读者情绪](../02_读者情绪/README.md)选一个主要目标。每篇中的人物和世界独立，不要未经调整就拼成连续正文。
