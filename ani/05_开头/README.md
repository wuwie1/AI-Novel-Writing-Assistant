开头先回答：谁遇到了什么具体问题，为什么必须行动，读者接下来能期待什么。六篇都含原创开篇片段、第一章收束方向和后三章建议，片段本身不是完整连载首章。

## 新手怎么选

职业与生活细节比较清楚，先选异常订单；能力规则比较清楚，先选首次付费；人物经历比较清楚，先选失去位置。倒叙需要先完成真实因果链，建议在知道事件完整经过后再写。

第一章至少推进一个小目标，留一个具体问题。第二至第四章用于验证能力、建立关系、完成首个小事件，再指向长线。这是练习框架，不是所有作品必须遵守的固定章数，更不是对平台推荐机制的判断。

## 写完检查

删去世界介绍，当前行动是否仍看得懂；读者是否知道主角最在乎什么；章尾的问题是否与本章事件有关；主角是否亲自作出过一次决定。所谓“黄金三章”不能代替这些判断，也不要求三章内必须打脸、拜师、退婚或开系统。
