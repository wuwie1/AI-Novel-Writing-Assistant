## 怎样避免只有设定、没有故事

先选一位有现实压力的普通人，再回答：能力帮他解决什么，为什么不能直接解决一切，第一次失败会失去什么，谁需要他、谁反对他。用一个小委托验证机制，再让委托结果引出下一个目标。

第一次开书建议选旧物回声，委托边界清楚，容易从小事写起。喜欢规则计算可选概率借贷；喜欢团队与城市生活可选夜班地铁。每次只选一个主要卖点，其他机制先作为背景。

## 长篇自检

列十个不同任务，检查它们是否只有同一种解法；检查能力能否无限刷资源、代价能否随意免除、普通人是否仍有贡献空间。再想一想城市就业、公共服务、商业与家庭如何受影响。异能若只有打斗时存在，都市背景就容易变成可随意替换的布景。

扩展能力时优先增加应用深度、协作与责任；新等级仍应遵守已有边界。设定可以服务爽感，也要留下需要人物亲自选择和承担的事情。
