# 社区契约与当代神职

类型：原创设定｜方向：都市玄幻、社区群像、当代民俗｜核心体验：力量来自具体的人，也要向具体的人负责。

## 一句话设定与主角

城市中的小型神职由居民自愿授权维持，守护者必须履行约定的公共服务才能续任。主角是社区社工唐禾，暂代一条老街的夜间守门职责，眼前任务是阻止连续发生的“门牌消失”。

## 世界规则

| 项目 | 本设定的规则 |
| --- | --- |
| 授权来源 | 一项写明范围、期限和责任的社区契约，需有持续有效的自愿参与者 |
| 能力范围 | 仅在约定边界内感知入口异常、维持基本结界；不能读心、命令人或处理一切纠纷 |
| 力量资源 | 已履行服务形成的有效记录，不以口号、盲目崇拜或单纯捐款换取 |
| 代价 | 守护时段内必须响应，体力与时间照常消耗，越过职责需要重新取得授权 |
| 退出 | 居民可以退出未来授权，守护者必须说明结界范围会怎样改变，不能报复或扣留 |
| 紧急规则 | 仅能动用契约预留的临时额度，事后须公开用途；不能无限宣称紧急状态 |
| 对手限制 | 他人无法伪造有效同意，但可以隐瞒信息、争夺支持或设计不公平条款 |
| 成长 | 扩大协作网络与职责能力；更大辖区需要更多参与者，不等于个人独裁升级 |

## 原创场景

唐禾准备封住一扇反复出现的旧门，住户刘阿姨却拒绝签字：“门后是我家以前的院子。”

同事催她先处理再解释。唐禾把封门符收回，带着记录员陪刘阿姨看了一次门内景象。

院子是真的留下了回声，进门的人却会忘记现实地址。她们约定保留一段受控探视时段，再共同封闭入口。结界因此多消耗一夜额度，唐禾得去其他住户家解释排班变化。

## 城市与组织

居民、物业、民俗保管人、职业守护者各有知识和权责。社区内部也有分歧，不能用一个投票替所有人作决定。神职是虚构职能，素材可以借民俗意象，但不要把自创条款当作真实信仰或现实公共治理规则。

## 首个篇章与长线

首个篇章：代班发现门牌异常 → 听取不同住户经历 → 验证旧门的风险 → 完成一次有限封闭并公开成本。长线可从邻里互信扩大到街区合并、新旧契约冲突，以及城市规模增长后如何保留退出与纠错机制。

## 怎么仿照与变体

保留“权力与具体责任绑定”的结构。变体可以是市场夜巡、校园旧楼守护、河道渡口神职；分别重写服务对象、授权方式和失职后果。不要只给传统神明加一张工牌，城市生活应改变任务本身。

## 参考建议与自检

检查拒绝主角的人能否有合理理由，弱势住户是否有表达机会，主角是否真的付出时间和资源。长线冲突不必靠“群众都愚昧”制造；两种合理需要也会争夺有限能力。

## 仿写练习

写一份五条以内的虚构职责约定，再设计一次双方都没有违约却产生冲突的事件。用 600 字让主角提出修订方案，并接受一个不能满足的请求。
