# 情绪共振与能力经济

类型：经典参照＋原创设定｜方向：都市玄幻、资源经营、群像｜核心体验：同一种资源机制持续改变人与人的交往。

## 经典参照

《大王饶命》，会说话的肘子著，将他人的负面情绪与主角成长资源联系起来。这里仅借此说明“资源获取方式能够影响日常行为”的设定思路，不沿用原作系统、人物或具体桥段。[参考：文艺报《超长篇网络小说成为阅读市场“香饽饽”》](https://wyb.chinawriter.com.cn/content/202308/25/content71410.html)

以下“情绪共振”是独立原创方案，资源规则与作用均重新设计。

## 一句话设定与主角

多人自愿参与同一活动时，可以把短暂共鸣留存在共振片中，为城市中的特殊设备供能。主角是独立音乐制作人闻霜，经营一间小排练室，靠真实合作获取能源，也要抵抗行业对情绪生产的过度索取。

## 能力与资源合同

| 项目 | 本设定的规则 |
| --- | --- |
| 触发 | 参与者事先知道用途并同意记录，至少三人在同一现场形成共同注意与情绪变化 |
| 可用情绪 | 喜悦、悲伤、紧张等都可形成资源，不预设负面情绪更值钱 |
| 转化边界 | 只能保存活动中自然形成的共鸣，不能读心，也不能强迫别人产生指定感受 |
| 消耗 | 记录后参与者会短暂疲倦，同一人在一天内不能重复贡献；单纯重播不能叠加资源 |
| 储存 | 共振片在二十四小时后开始快速衰减，无法无限囤积 |
| 用途 | 驱动隔音结界、公共引路灯等特定设备，不能直接当万能法力或现实电能 |
| 分配 | 参与者约定去向；转交必须保留记录与使用范围，不能悄悄用于其他目的 |
| 成长 | 主角学会组织不同伙伴与场地，扩大合作质量；单人无法取代整个团队 |

## 原创场景

排练到最后一遍，闻霜让大家停下。音准和节拍都够了，共振片却始终不亮。

鼓手问是不是要再激动一点。

她摇头，把原本只属于主唱的一段空拍分给每个人。年纪最大的贝斯手跟不上，几人放慢速度，等他接住最后一个音。

片子亮了一下，能量很少，只够点亮楼道一晚。闻霜照约定把它交给住户代表，没有因为观众少就要求乐手再来一次。

## 城市与组织

小场地、公共活动与大型演出公司争夺参与者时间。公司可以通过更好的服务提高效率，也可能隐瞒疲倦成本、挪用用途或压低报酬；不能简单规定商业机构全坏。城市必须保有普通设备与备用能源，不能逼所有人靠持续高强度情绪维持生活。

## 首个篇章与长线

首个篇章：接一项小型供能委托 → 因过度排练失败 → 调整合作方式 → 完成约定并分配收益。长线围绕共振资源的流通、伪造授权的交易与城市应急需求展开。重要矛盾是怎样获得、怎样使用，升级不只是参与人数越来越多。

## 怎么仿照与参考建议

先选你想写的人际行为，再设计会鼓励它的资源规则。变体可以围绕共同完成承诺、互相教授技能或多人协同记忆展开；相应地重写触发与代价。别仅把“负面情绪值”换成“感动值”，仍复制同样的获利方式和人物反应。

## 仿写练习

设计一次参与者可以拒绝的合作，让主角在提高产量与照顾伙伴之间作选择。写清普通替代方案、资源归属和真实成本，再写 700 字冲突场景。检查角色是否还有情绪资源之外的个人目标。
