# 梦境维修与睡眠债务

类型：原创设定｜方向：都市异能、职业冒险、人物关系｜核心体验：进入奇异空间，仍需尊重梦主的选择。

## 一句话设定与主角

少数人能进入受外来灵质污染的共享梦境，修补它与现实之间的裂口，但不能删除人的真实记忆或替人改变心意。主角许眠白天给剧场做布景，夜里兼职梦境测绘，想偿还为救搭档欠下的睡眠债务。

## 能力合同

| 项目 | 本设定的规则 |
| --- | --- |
| 入口 | 梦主清醒时同意，双方预设唤醒信号并持有配对锚物；无同意不能进入私人梦境 |
| 能做到 | 识别外来裂口、修补梦内空间连接、带回自己记录的有限信息 |
| 做不到 | 凭空治愈心理疾病、保证梦境记忆真实、直接控制梦主情绪或删除痛苦经历 |
| 时间 | 梦内四十分钟对应现实十分钟，单次最长现实半小时，超时必须退出 |
| 代价 | 每进入十分钟，需要额外一小时恢复睡眠；债务达到四小时后无法再次入梦 |
| 锚点 | 锚物受损会丢失返回定位，但预先约定的外部唤醒仍是独立保障 |
| 对抗 | 污染物可改变局部场景，不能伪造配对锚物的共同记录 |
| 成长 | 学会辨认空间与情绪的关系，扩大协作能力；不靠升级免除休息 |

## 原创场景

梦里的剧场只有一扇门，每次打开都回到观众席。许眠想把门拆掉，梦主却拦住她：“拆了，演员就没地方谢幕。”

她重新检查舞台，发现裂口藏在永远无人坐的最后一排，而不是出口。

她先搭了一座临时台阶，让梦主走近那排座位。梦主选择留下空位，却同意封住座位下不断渗出的黑水。

醒来后，对方没有突然释怀一切，只能终于睡满一个正常夜晚。许眠把还没完成的布景工作交给搭档，按记录补觉。

## 城市与组织

剧场、宿舍、夜班行业提供人物与场景；专业梦境事务所负责异常污染委托，现实中的健康问题由相应专业人员处理。保险机构想量化工作时长，雇主想压低恢复成本，形成劳动与信任冲突。梦境奇观必须对应委托人的具体生活。

## 首个篇章与长线

首个篇章：接一个小空间的修补单 → 因误认象征而选错修复点 → 学会询问梦主 → 找到外来裂口并按时退出。长线围绕一批共享梦境的污染来源、恢复时间被侵占的维修员，以及搭档那次事故的真实经过展开。

## 怎么仿照与变体

保留“象征空间＋可操作规则＋现实关系后果”。可换成反复出现的校园、无法到站的列车或只在雨夜开放的商场。每个空间先确定一条稳定规则，不能把所有逻辑漏洞都解释为“这是梦”。

## 参考建议与自检

梦中说法不是自动可靠的证词，回到现实仍需验证。修复超自然裂口不等于替人完成心理治疗。要检查入梦同意、退出方案和时间上限在危机时是否仍有效，且角色不能无限靠咖啡抵消睡眠债务。

## 仿写练习

设计一个三房间梦境，每个房间对应一个现实困境，但只有一个真正的污染点。写 600 字，让主角通过询问而不是强拆解决问题，并支付一次明确的休息成本。
