# 夜班地铁与灵脉交通

类型：原创设定｜方向：都市玄幻、职业群像、城市冒险｜核心体验：现代交通体系背后的第二张地图。

## 一句话设定与主角

普通地铁停运后，少数轨道借城市灵脉连接现实地图上不存在的站点；每次开行都会占用有限的城市维护资源。主角是夜间线路调度员林青，先想平安完成试用期，后来要查清一处被取消的站点为何仍有人等车。

## 世界规则

| 项目 | 本设定的规则 |
| --- | --- |
| 开行条件 | 现实轨道完成检查、两端锚点有效、沿途维护额度足够 |
| 入口 | 指定站台与时段，普通乘客不会随机被吸入；异常误入属于事故，需要追查 |
| 通行凭证 | 实名绑定的临时线路许可，只对应指定行程，不是全城万能钥匙 |
| 资源 | 节点每夜可承担的灵压有限，超额开行会压缩其他站点的维护能力 |
| 失败后果 | 丢失锚点的车必须停在最近安全站，不能靠意志强行穿回现实 |
| 主角能力 | 能看见线路之间的短时共振，最多提前十秒发现一次路径不稳定 |
| 能力限制 | 必须看见真实调度图，不能预知乘客意图；连续观察会失去色差辨识，需要轮班 |
| 成长路线 | 从单站调度到跨线协调，依赖图纸、伙伴与资源协商，而非无限延长预知 |

## 原创场景

林青准备取消一班没有登记乘客的车，站台值守却发来一张照片：雾里摆着七只装满药材的篮子。

“没人上车，不代表没人收货。”

调度图上的末站已经注销。林青要求核验收货记录，发现那是为一处隔离社区保留的夜间补给线。

多开一班会占用东线的检查时段。他必须先和检查队协调，不能只在调度台上按一个充满人情味的按钮。

## 城市与组织

运营方、维护工会、沿线居民和灵物商户有不同诉求。普通白班交通优先，夜班组织必须解释资源从哪来、故障谁负责。现代城市的地图、排班、商贸与公共服务都实际影响超凡活动，不能把地铁只当装饰性的秘境入口。

## 首个篇章与长线

首个篇章：接到注销站的货运请求 → 核实站点仍有人生活 → 修复一处锚点 → 协调资源完成首班补给。长线可围绕失联线路、隐瞒的维护账单与城市扩建展开，升级单位从一站、一线到全城；每次扩大范围都增加协作难题。

## 怎么仿照与变体

保留“熟悉公共系统＋隐藏用途＋共享资源冲突”。可换成夜间公交、水运航道或旧城电梯，但要重做空间规则和岗位分工。把真实交通知识与幻想规则分开记录，需要写实操作时另查资料。

## 参考建议与自检

先回答为什么只有这些路线能通、为什么不能随意加车、为何普通居民仍能正常生活。事故不能全靠主角提前看十秒解决；制度故障与资源不足需要群像参与。不要用无来源的“秘密部门”解释所有责任空缺。

## 仿写练习

画一张四站线路表，给每站一个用途、一项限制和一个需要帮助的人。写 600 字调度争执，让双方都提出有道理的方案，最终选择留下一项后果。
