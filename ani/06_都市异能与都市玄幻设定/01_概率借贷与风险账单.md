# 概率借贷与风险账单

类型：原创设定｜方向：都市异能、规则成长、轻悬疑｜核心体验：用精确选择换取有限优势。

## 一句话设定与主角

普通人能为一次本来可能成功的小行动借来好运，但必须事先接受一项范围明确的未来失误。主角是活动执行员苏遥，想保住第一次独立承办的社区展会；她擅长准备和协调，异能只能补缺口。

## 能力合同

| 项目 | 本设定的规则 |
| --- | --- |
| 触发 | 对一个即将发生、结果尚未确定的本人行动提出借用，报价后主动确认 |
| 能做到 | 提高已有可行路径的成功机会，如恰好排除卡纸、找到尚未丢失的票据 |
| 做不到 | 创造不可能事件、改写已发生事实、指定他人情感、直接改变人身安全结果 |
| 初始额度 | 每天最多三格；一次事件不能拆成多个请求重复借用 |
| 代价 | 使用前展示失误范围与截止时间，默认由本人承担金钱、时间或机会损失 |
| 偿还 | 接受约定范围内的一次失误；无法在期限内结算则冻结后续额度，并保留原账单 |
| 防止套利 | 不能对抽奖、博彩和纯粹倒卖额度报价；同一结果不能靠重复提问刷新报价 |
| 成长 | 提高对报价原因的理解与任务拆解能力；额度缓慢增加，旧账不会因升级清零 |

这是幻想规则，不声称真实概率能够这样计量。触发范围应在写正文前确定，不能在高潮时突然允许借命、改历史。

## 原创场景

展会开幕前，最后一台投影仪熄了。苏遥看见报价：借两格，让备用灯泡成功点亮；今晚承担一次已预约交通失约。

她差点答应，随后看见墙边还有一块白幕。

“把讲解移到院子里。视频我改成现场演示。”

报价消失了。她留着最后两格，要等参展老人那批最重要的作品运到。能力第一次帮到她，不是因为她用了它，而是它迫使她认真衡量了什么值得付费。

## 城市与组织

少数借用者组成互助登记站，提供账单解释和任务复盘，不替人神秘免债。活动公司想把员工额度算进生产指标，互助站主张借用必须由本人同意。普通城市仍靠准备、劳动和公共服务运转，异能不能替代所有流程。

## 首个篇章与长线

首个篇章：小额借用成功 → 交通失约产生真实成本 → 为展会测试边界 → 拒绝一次诱人的借用 → 用普通准备加一次关键额度完成活动。长线冲突从个人债务转向企业如何使用员工的能力，以及有人是否在隐瞒报价中的机会成本。

## 怎么仿照与变体

保留“收益先见、代价可追踪、选择会累积”的机制。把主角职业换成记者时，机会成本可以是错过一次采访；换成竞赛选手时，应先明确比赛是否允许能力。若改为借时间，重写偿还规则，不把概率系统整套换名搬过去。

## 参考建议与自检

先问三件事：能否连续借用刷出无限收益；代价会不会偷偷转嫁路人；主角遇到问题是否还需要做准备。任何一项失控都应回到规则修正。不要靠突然索命制造深度，日常机会的错失也能形成重要后果。

## 仿写练习

列三张账单：值得借、不值得借、因信息不足暂缓。各写收益、已知代价和替代方案，再选一张写 600 字完整结算戏。
