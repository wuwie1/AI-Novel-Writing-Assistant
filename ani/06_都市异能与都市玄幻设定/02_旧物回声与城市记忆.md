# 旧物回声与城市记忆

类型：原创设定｜方向：都市异能、职业调查、温情悬疑｜核心体验：从小物件找回被忽略的人与事。

## 一句话设定与主角

旧物修复师可以在修复断裂处时，听见该物件经历过的一小段强烈声音，但声音没有完整上下文。主角宁禾想保住街角修理铺，也想找到母亲当年没有交付的一件委托。

## 能力合同

| 项目 | 本设定的规则 |
| --- | --- |
| 触发 | 亲手修复物件的一处真实损伤，完成后触碰修复点 |
| 信息来源 | 该物件在损伤发生附近记录的最强声音，通常只有数秒 |
| 信息边界 | 不提供说话人身份、准确日期、未发生的事件或物件不在场的事情 |
| 代价 | 每次读取后，自己的最近十分钟记忆会暂时混淆，需与事先记录核对；一小时内不可再读 |
| 重读限制 | 同一损伤只留下同一片段；故意打坏再修不能回看更早经历 |
| 干扰 | 后续噪声可能覆盖片段，仿造品只记录自身经历，不继承原件记忆 |
| 成长 | 从分辨单一声源到比较多个片段；提高修复技术，不发展成全知读心 |
| 证据边界 | 回声提供调查方向，公开结论需要独立记录、物证或证人核实 |

## 原创场景

宁禾修好一只旧饭盒，听见有人说：“别告诉她，我明天就回来。”

委托人认出父亲的声音，坚持那是他失踪前的承诺。宁禾却在背景里听见车站卖水的吆喝，与父亲工作的码头不符。

她没有宣布父亲遭了什么事。她把饭盒放进证物袋，在纸上写下能确认的三项声音，等自己的记忆恢复后再核对。

第二天，她们找到那个早已搬走的摊主，才知道这只饭盒曾经被借给过另一个人。

## 城市与组织

旧货市场、博物馆、修复工坊和搬迁家庭提供自然委托。行业协会关注物件归属与读取同意，收藏商则可能更重视稀有回声的价格。城市改造会使旧物集中流转，也带来哪些记忆应该保存、谁有权公开的冲突。

## 首个篇章与长线

首个篇章：找到丢失物的主人 → 因误读声源作出错误猜测 → 与普通调查者合作补证 → 完成一件有情感回报的委托。长线把几件互不相关的旧物连向一次旧城区事故；主角逐渐发现母亲留下的委托与事故有关，但不能每件旧物都恰好指向她。

## 怎么仿照与变体

保留“有限感官片段＋职业验证＋现实关系”，重做感官与载体：陶器保存触感、织物保存动作方向、照片记录被裁掉的光影。每换一种感官，就重新规定缺失信息与误读方式，不能只改能力名字。

## 参考建议与自检

最容易写坏的是让回声直接播放整段真相。每条线索至少区分“听见的事实”和“人物作出的推断”。也要回答普通人为何需要主角、为何不一次性读遍全城物件，以及客户为什么愿意交出东西。

## 仿写练习

选择一件真实生活中常见的旧物，写 150 字回声和两个合理解释，再设计一条普通证据排除其中一个。用 500 字写委托人与主角的意见分歧。
