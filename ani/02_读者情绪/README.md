# 读者情绪

让读者在乎人物的目标，再改变他们对结果的预期。情绪是读者对事件与关系的反应，不能靠正文反复说“感动、震惊、愤怒”替代。

| 条目 | 主要用途 | 关键准备 |
| --- | --- | --- |
| [不公与愤怒释放](01_不公与愤怒释放.md) | 让纠错与反抗有分量 | 先展示付出和应得之物 |
| [信息差与期待兑现](02_信息差与期待兑现.md) | 让读者想看主角亮相 | 提前展示优势及使用条件 |
| [倒计时与悬念焦虑](03_倒计时与悬念焦虑.md) | 在行动中收紧压力 | 建立关心对象与真实期限 |
| [日常回声与克制悲伤](04_日常回声与克制悲伤.md) | 表现关系失去后的余痛 | 先让共同习惯存在 |
| [被理解与关系温暖](05_被理解与关系温暖.md) | 形成信任与归属 | 写出未被说出的具体需要 |
| [认知错位与喜剧释放](06_认知错位与喜剧释放.md) | 调整节奏、建立人物亲近感 | 给双方不同但合理的理解框架 |

## 最小练习方法

一场戏先选一种主要情绪，再写一句“读者希望……，但担心……”。安排三个推动这种预期变化的动作，最后给予兑现或明确改变。先练期待与温暖，再练需要前文积累的悲伤。

高压段落之间允许处理伤口、吃饭、对账和聊天，只要这些事在改变关系或后续选择。不要把每章都写到最高强度；对同样的刺激持续加码，可能让读者麻木。

试读时问具体位置：“你从哪一段开始在乎他？”“哪一次拖延让你想跳过？”不要只问“感不感动”。本库提供机制假设，实际效果要结合目标读者的反馈调整。
