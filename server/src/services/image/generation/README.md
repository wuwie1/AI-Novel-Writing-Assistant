# 图片生成请求取消

`cancellation.ts` 属于图片任务执行适配层，以已存在的 `cancelRequestedAt` 和任务状态为取消事实来源，每 500ms 检查一次。执行器将信号传给供应商请求，退出时必须释放定时器。

取消优先于供应商错误和自动重试。执行器捕获错误后还需读取一次持久化状态，避免取消标记与网络错误同时到达时把任务重新排队。取消仅结束本地调用和后续流程，不能保证供应商在已接收请求后撤销计费。

供应商请求同时接收任务停止信号与小说执行作用域的取消信号，不能为接入其中一种而覆盖另一种。删书可能先移除图片任务，存储写入随后才返回；任务已不存在时，应登记尚未清理的封面并结束执行，不能再写入取消状态或重新排队。任务仍在时，停止只取消本次生成，保留小说与已保存资产。
